# Hey, I'm Nevin 👋

Systems Engineer with a specialty in Database Systems: OLAP, Metadata Management, Storage, Query Engines & Processing.

## Background

I have a Masters in Computer Engineering from Carnegie Mellon, where I got inspired by databases and knew I wanted to pursue them as a career.

I spent ~5 years at Google working on **BigQuery** internals — the streaming layer, storage APIs, and the machinery that moves petabytes between query engines and cloud storage. I learned what it takes to build systems that work at massive scale: the engineering rigor, the failure modes you'd never predict, and the operational discipline to keep it all running.

## What I'm Interested In

- **Storage engines** — how data is laid out on disk and accessed efficiently
- **Query engines** — planning, optimization, and execution
- **Streaming systems** — high-throughput data pipelines that keep consumers fed
- **Columnar formats** — Parquet, Arrow, Vortex, and the tradeoffs between them
- **Distributed systems** — coordination, consistency, and the places where theory meets messy reality
- **OLTP** — interested in branching into transactional systems and exploring that side of the database world
